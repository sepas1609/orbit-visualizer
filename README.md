# 🔮 Orbit Visualizer — 3D Celestial Orbit Synthesis

An interactive 3D WebGL orbital dynamics laboratory rendered with Three.js.

## 🌌 Mathematical Mechanics
- **Keplerian Conic Sections**: Orbital geometries derived from standard gravitational parameter $\mu = GM$ and eccentricity vector $\vec{e}$.
- **Audio-Reactive Resonators**: Celestial pulse rings expand in frequency synchronization with procedural synthesizer harmonics.
- **Three.js Pipeline**: Instanced mesh buffers for high-density particle ring generation at 60 FPS.
